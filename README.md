# hxwl-11 眼科验光记录

视力、屈光参数与复查处方版本链管理

## 技术栈

React + Vite + TypeScript + CSS（localStorage 持久化，无后端依赖）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5111

## 验光复查闭环规则

1. **继承上次处方**：同一患者点「新增复查」，自动把最新版本的双眼球镜、柱镜、轴位、视力、瞳距预填进表单，在其基础上修改。
2. **超阈值必须填原因**：球镜或柱镜变化 **超过 0.50D**（恰好 0.50 不算）、轴位变化 **超过 0.50°** 时，该字段必须填写变更原因（≥5 字），否则无法提交。
3. **轴位范围**：只接受 0-180 的整数，环向计算差值（178°↔2° = 4°）。
4. **只追加，不覆盖**：提交后生成递增版本号（v1、v2…），旧处方的旧值、变更原因与时间戳原样保留；版本链存入 localStorage，刷新后仍在。
5. 首启内置 3 位演示患者（Patient-032 / 081 / 144），其中 032、144 已含带变更原因的复查版本。

## 代码结构

- `src/types.ts` — 处方、版本、变更留痕领域模型
- `src/rules.ts` — 阈值、轴位环向距离、变更检测与格式化
- `src/storage.ts` — append-only 本地持久层、按患者分组与版本号
- `src/seed.ts` — 演示数据
- `src/PrescriptionForm.tsx` — 继承预填、实时差值、校验与原因录入
- `src/VersionTimeline.tsx` — 不可变版本链时间线
- `src/App.tsx` — 患者档案、看板与闭环编排
