# hxwl-11 眼科验光记录

视力、屈光参数与复查处方对比 —— 验光复查闭环

## 技术栈

React + Vite + TypeScript + CSS，本地用 localStorage 持久化版本链（无后端）。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5111

## 校验与测试

```bash
npm run typecheck   # tsc 严格类型检查
npm test            # 领域规则 + 持久化闭环测试（16 项断言）
npm run build       # 生产构建
```

## 业务规则

- **复查继承**：对同一患者新增复查时，表单自动带入最新一版处方（球镜、柱镜、轴位、
  矫正视力、瞳距、分类、验光师）。
- **超限必填原因**：右眼/左眼的球镜、柱镜绝对差值 **严格大于 0.50D**，或轴位最短夹角
  **严格大于 0.50°**（0° 与 180° 等价）时，必须填写变更原因，否则无法提交；
  恰好 0.50 不触发。
- **轴位约束**：仅允许 0-180 的整数；无柱镜（填 0）时轴位锁定不填。
  屈光度数须为 0.25D 的整数倍。
- **只增不改**：每次提交（初配或复查）都生成一个全新的不可变版本，版本号递增，
  记录 `inheritedFromVersion` 继承链；旧版本的参数、变更旧值/差值/原因、
  检查日期与提交时间戳原样保留，任何路径都不覆盖旧处方。
- **刷新持久化**：全量档案存于 localStorage（key：`hxwl-11.patients.v1`），
  刷新或重新打开后版本链仍在。首次打开自动生成 3 名带多版本链的示例患者
  （种子数据同样经过版本构建器与原因闸门校验）。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `src/types.ts` | 患者、不可变处方版本、变更条目等类型 |
| `src/domain.ts` | 纯领域逻辑：屈光度/轴位校验、最短夹角、0.50 阈值、差异对比、版本构建器 |
| `src/storage.ts` | localStorage 读写与种子数据（经版本构建器构建） |
| `src/RxForm.tsx` | 初配/复查表单：继承上次处方、实时差异、超阈值原因必填 |
| `src/PatientDetail.tsx` | 患者详情与版本链时间线（旧值、原因、时间只读展示） |
| `src/App.tsx` | 视图路由、看板指标、患者列表/筛选、不可变 append 提交 |
